# 🦅 HAWK EYE

### Nmap Automation & Recon Tool

HAWK EYE is a Python-based Nmap automation and reconnaissance tool designed for Kali Linux and authorized security testing environments.

> ⚠️ **AUTHORIZED USE ONLY:** Use HAWK EYE only on systems, networks, or applications that you own or have explicit permission to test.

---

## 🚀 Features

- Quick Nmap Scan
- Common Port Scan
- Specific Port Scan
- Full TCP Port Scan
- Service Detection
- OS Detection
- Aggressive Scan
- Custom Nmap Arguments
- Automated TXT Report Generation
- Simple CLI Interface
- Green-on-Black Terminal Interface

---

## 🛠️ Requirements

- Kali Linux
- Python 3
- Nmap

---

## 💻 Installation

Clone the repository:

git clone https://github.com/Anas-Abdullah-Sec/Hawk-Eye.git
cd Hawk-Eye

Install Nmap if it is not already installed:

sudo apt update
sudo apt install nmap -y

Run HAWK EYE with:

python3 Hawk_Eye.py

The tool will prompt you to enter an IP address or domain name and select the desired Nmap scanning option.
